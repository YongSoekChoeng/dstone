# Git

## 1. 개요
dstone 소스 코드 형상관리 도구.

## 2. 설치 정보
- 버전: 2.53.0
- 설치 방식: Ubuntu 공식 저장소 apt 패키지

## 3. 설치 방법
```bash
sudo apt update
sudo apt install -y git
```

설치 확인:
```bash
git --version
```

## 4. 설정
사용자별 `user.name`/`user.email` 등은 `git config --global`로 각자 환경에서 설정한다. 별도의 사내 Git 서버/인증 설정이 추가되면 이 문서에 기록한다.
