## 1. 개요

브라우저를 MCP Tool로 다루게 해 주는 서버(`@playwright/mcp`)와, 그 서버가 띄우는 헤드리스 Chromium이다.
dstone-ai-engine의 전문가 해결 Agent(`sm-troubleshooter-agent`)가 시험 서버의 화면을 직접 열어 증상을 재현하고,
콘솔 오류와 네트워크 응답을 보는 데 쓴다. 상시 떠 있는 서비스가 아니고, ai-engine이 기동할 때 STDIO 프로세스로 띄운다.

## 2. 설치 정보

- 설치일: 2026-11-22
- 버전: `@playwright/mcp` 0.0.86, `playwright-core`(함께 설치됨)가 요구하는 Chromium Headless Shell 159.0.8154.6 (playwright revision 1255)
- 설치 위치: `/opt/playwright-mcp` (소유자 `jysn007`)
  - `node_modules/@playwright/mcp/cli.js` — MCP 서버 실행 파일
  - `browsers/chromium_headless_shell-1255/chrome-headless-shell-linux64/chrome-headless-shell` — 브라우저 실행 파일
  - `browsers/chromium-1255`, `browsers/ffmpeg-1013` — 설치 명령이 함께 받은 것(지금은 쓰지 않음)
  - `output/` — MCP 서버가 스크린샷 등을 남기는 폴더(`--output-dir`)
- 필요한 것: Node.js 20 ([13.nodejs.md](13.nodejs.md))
- 포트: 없음(STDIO)
- 참고: `~/.cache/ms-playwright`에 있는 Chromium 1243은 이전 작업에서 받은 것으로, 이 서버는 쓰지 않는다(버전이 다름).

## 3. 설치 방법

```bash
sudo mkdir -p /opt/playwright-mcp && sudo chown $USER:$USER /opt/playwright-mcp
cd /opt/playwright-mcp
npm init -y
npm install --no-fund --no-audit @playwright/mcp@0.0.86
# 브라우저는 같은 폴더 아래에 받는다(폐쇄망으로 옮길 때 폴더 하나만 복사하면 되도록)
PLAYWRIGHT_BROWSERS_PATH=/opt/playwright-mcp/browsers node node_modules/playwright-core/cli.js install chromium
```

설치 확인(Tool 목록이 나오면 정상):

```bash
cd /opt/playwright-mcp
(printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"t","version":"1"}}}' \
  '{"jsonrpc":"2.0","method":"notifications/initialized"}' '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'; sleep 4) \
 | node node_modules/@playwright/mcp/cli.js --headless --isolated \
   --executable-path /opt/playwright-mcp/browsers/chromium_headless_shell-1255/chrome-headless-shell-linux64/chrome-headless-shell
```

## 4. dstone 프로젝트에서의 역할

| 위치 | 내용 |
|---|---|
| `dstone-ai-engine/conf/definitions/mcp/common/browser.yml` | MCP 서버 정의(id `browser`). `npx -y` 대신 설치한 `cli.js`를 `node`로 바로 띄운다. 임의 코드 실행 Tool은 열지 않는다 |
| `dstone-ai-engine/conf/env-wsl.properties` | `PLAYWRIGHT_MCP_HOME=/opt/playwright-mcp`, `PLAYWRIGHT_BROWSER=…/chrome-headless-shell` |
| `dstone-ai-engine/conf/env.properties`(Windows) | `C:/DEV/UTIL/Playwright-mcp` 기준(6절). `env-k8s.properties`는 비워 두어 서버를 띄우지 않는다 |
| `sm-troubleshooter-agent` | `browser_*` Tool로 화면을 재현한다. 기본은 임시 시험 서버(`startTestServer`)에서, 로그인은 프로젝트 관리의 시험계정으로 한다(비밀번호는 자리표시자) |

### 시험 서버 구성 (대상 앱마다 현장에서)

Agent가 고친 결과를 올려 볼 시험 서버는 대상 앱마다 다르다. 저장소에는 특정 앱의 값을 두지 않고, 현장에서 아래를 채운다.

| 항목 | 채우는 곳 |
|---|---|
| 임시 시험 서버(기본) | Tool `startTestServer`가 `{TEST_SERVER_WORK_ROOT 또는 ~/.dstone-ai-engine}/{프로젝트ID}-server/`에 사본을 만들어 빈 포트로 띄우고, 접속 주소와 서버 로그 경로를 돌려준다. WAR는 `TEST_SERVER_TOMCAT_HOME`의 Tomcat(전용 CATALINA_BASE), JDK는 `JAVA_HOME_{버전}` |
| 시험 계정 | ai-engine 프로젝트 관리의 시험계정(시험 서버 전용 계정만, 비밀번호 암호화). 요청서에는 적지 않는다. Agent는 비밀번호 대신 자리표시자 `${secret:프로젝트ID.testPassword}`만 받는다 |
| 사람이 쓰는 시험 서버(선택) | 요청서의 `반영폴더`·`반영명령`·`접속주소`·`서버로그`. 반영 스크립트는 `env*.properties`의 `TEST_SERVER_DEPLOY_SCRIPT`(→ `dstone.ai.tool.shell.allowed-commands` 이름 `test-server-deploy`) |
| DB | 요청서의 `프로젝트ID`로 ai-engine 프로젝트 관리에 등록한 DB(읽기 전용 계정 권장, 별칭 `프로젝트ID.DB이름`). 프로젝트에 묶이지 않은 DB는 `application.yml`의 `dstone.ai.tool.db.connections`에 등록하고 요청서의 `DB연결`에 별칭을 적는다 |

요청서 양식은 `docs/09.dstone-ai-engine.md` 11.1절이다.

## 5. 폐쇄망(오프라인) 설치

인터넷이 되는 같은 OS(리눅스 x64)에서 3절대로 설치한 뒤, `/opt/playwright-mcp` 폴더를 통째로 복사한다.
`node_modules`와 `browsers`가 모두 그 안에 있으므로 폐쇄망 쪽에서 내려받을 것이 없다. Node.js 설치 파일은 따로 가져간다.

- Windows 서버라면 6절대로 설치한 폴더를 통째로 옮긴다.
- 브라우저를 따로 들이기 어려우면 서버에 이미 있는 Edge를 쓸 수 있다. 이때는 `browser.yml`의 `--executable-path` 대신 `--browser msedge`를 쓴다.

## 6. Windows 설치

개발 PC(Windows)에는 2026-11-22에 `C:\DEV\UTIL\Playwright-mcp`에 설치했다. `@playwright/mcp` 0.0.86, Chromium Headless Shell rev 1255(`chrome-headless-shell-win64`). Node.js는 `C:\DEV\CLIENT\NodeJs\26.13.1`을 쓴다.

```powershell
mkdir C:\DEV\UTIL\Playwright-mcp
cd C:\DEV\UTIL\Playwright-mcp
npm init -y
npm install --no-fund --no-audit @playwright/mcp@0.0.86
$env:PLAYWRIGHT_BROWSERS_PATH = "C:\DEV\UTIL\Playwright-mcp\browsers"
node node_modules\playwright-core\cli.js install chromium
```

`conf/env.properties`(Windows 프로파일):

```properties
PLAYWRIGHT_MCP_HOME=C:/DEV/UTIL/Playwright-mcp
PLAYWRIGHT_BROWSER=C:/DEV/UTIL/Playwright-mcp/browsers/chromium_headless_shell-1255/chrome-headless-shell-win64/chrome-headless-shell.exe
```

- `MCP_STDIO_COMMAND_PREFIX=cmd.exe /c`는 그대로 둔다. ai-engine을 띄우는 환경의 PATH에 Node.js 폴더가 있어야 `node`를 찾는다.
- 설치 확인: 3절의 확인 명령을 `node node_modules\@playwright\mcp\cli.js --headless --isolated --executable-path <위 브라우저 경로>`로 돌려 Tool 목록(25개)이 나오면 된다. ai-engine 로그에는 `mcp: [browser] 접속 성공 - Tool 25개 중 13개 등록`이 남는다.
- 확인할 때 `--output-dir`을 주지 않으면 지금 폴더에 `.playwright-mcp` 폴더가 생긴다. ai-engine은 `{PLAYWRIGHT_MCP_HOME}/output`을 쓴다.
