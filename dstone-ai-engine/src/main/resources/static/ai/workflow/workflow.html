Workflow 테스트

Workflow 하나를 골라 입력값을 넣고 실행해 봅니다. 실행은 엔진에서 따로 돌고, 이 화면은 5초마다 상태를 확인해 끝나면 결과를 보여 줍니다. 승인을 기다리는 실행은 Workflow 실행 관리에서 승인하거나 반려합니다.

개발자용: 이 화면이 부르는 API

GET /api/ai/workflow(목록), POST /api/ai/workflow/{workflowId}/submit(실행, executionId를 바로 돌려줌), GET /api/ai/workflow/executions/{executionId}(상태). 상태는 QUEUED → RUNNING → DONE / FAILED / WAITING_APPROVAL 순으로 바뀝니다.
