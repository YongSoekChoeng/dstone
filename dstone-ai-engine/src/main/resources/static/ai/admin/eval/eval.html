Agent 평가

실제로 있었던 일을 문제(평가 사례)로 고정해 두고, Agent에게 다시 풀게 해서 채점합니다. Agent 정의·Skill·모델을 바꾸기 전과 후를 같은 사례로 돌려 나아졌는지 비교합니다.

알아 둘 것

평가는 실제 LLM을 부르므로 비용이 듭니다. 한 사례가 몇 분 걸릴 수 있고, 평가는 한 번에 하나씩 차례로 돕니다. 사례는 엔진의 conf/eval 아래 *.eval.yml 파일이고, 고치면 다시 띄우지 않아도 바로 보입니다. 시험 서버를 쓰는 사례는 그 서버의 데이터를 바꿀 수 있습니다(사례 설명을 확인하세요). Agent가 만든 파일은 결과의 작업 폴더에 남습니다.
