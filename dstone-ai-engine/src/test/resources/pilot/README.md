# pilot 신규 개발 경로 - 회귀 테스트 자료

`tools.pilot.PilotNewdevLogicTest`가 읽는 파일입니다.

| 파일 | 내용 |
|---|---|
| `newdev-input.json` | Agent가 낸 데이터(요구사항/구성 정의, 참고 구현, 파일별 설계)와 파일 Tool의 결과를 흉내 낸 입력 |
| `newdev-expected.json` | 같은 입력에서 나와야 하는 결과(검증 문구, 문서 4종, 적용할 변경 목록) |

`newdev-expected.json`은 손으로 쓴 것이 아닙니다. 이 로직을 Workflow YAML의 jq 표현식에서 자바로 옮길 때(2026-10-09),
옮기기 전의 jq 식을 jackson-jq 1.6.5로 실제로 실행해서 얻은 값입니다. 그래서 이 테스트가 통과하면
"자바로 옮긴 로직이 옮기기 전과 같은 문서를 만든다"는 뜻입니다.

입력은 갈래를 빠짐없이 타도록 일부러 만든 것입니다(없는 참고 파일, FR이 없는 범위, 중복된 변경 대상, 실패한 설계,
변경 전이 0번/2번 나오는 수정, 복사 실패, 편집 Agent 호출 실패, 괄호 주의가 붙은 적용 결과 등).

문서의 모양을 일부러 바꿨다면 `newdev-expected.json`의 해당 값을 새 모양으로 고칩니다.
