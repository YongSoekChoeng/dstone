## 신규기능

### 이미지 게시판 개발 (메뉴위치: 테스트 > 이미지게시판)

| 번호 | 목적 | 대상 메뉴·기능 | 요구 내용 | 선행 태스크 | 완료 기준 | 상태 |
|------|------|----------------|-----------|-------------|-----------|------|
| TASK-01 | 이미지 게시물 등록·수정·조회를 위한 상세화면 팝업 구현 | 테스트 > 이미지게시판 > 상세화면(팝업) | ① 항목: 제목, 등록자(로그인 사용자명 자동세팅), 파일업로드버튼 ② 파일업로드버튼 클릭 시 로컬 이미지 파일 선택 가능 ③ 저장버튼: 등록내용 저장 ④ 수정버튼: 등록내용 수정 ⑤ 편집모드(신규등록)와 조회모드(제목 클릭 시)로 노출 | - | 편집모드에서 제목 입력·파일 업로드·저장 시 게시물이 등록되고, 수정모드에서 내용 변경·저장 시 반영되며, 조회모드에서 읽기전용으로 표시됨 | 통과 |
| TASK-02 | 썸네일 클릭 시 원본 이미지를 크게 볼 수 있는 이미지 뷰어 팝업 구현 | 테스트 > 이미지게시판 > 이미지 뷰어 팝업 | ① 목록의 썸네일 클릭 시 해당 이미지 원본을 팝업으로 노출 | - | 썸네일 클릭 시 원본 이미지가 팝업으로 표시되고, 닫기 시 목록으로 복귀 | 통과 |
| TASK-03 | 이미지 게시물 목록 조회·검색·삭제 기능을 위한 목록화면 구현 | 테스트 > 이미지게시판 > 목록화면 | ① 테이블: 체크박스, SEQ, 썸네일, 제목, 등록자 ② 페이징 처리 ③ 조회조건: 제목 ④ 기능버튼 - 전체선택: 클릭 시 체크박스 전체 체크 - 등록: 상세화면 팝업 편집모드로 노출 - 삭제: 체크된 게시물 삭제 ⑤ 이벤트: 제목 클릭 → 상세화면 팝업(조회모드), 썸네일 클릭 → 이미지 뷰어 팝업 | TASK-01, TASK-02 | 목록에 등록된 게시물이 SEQ·썸네일·제목·등록자로 표시되고, 페이징·제목 검색·전체선택·삭제가 정상 동작하며, 제목/썸네일 클릭 시 각각 상세 팝업(조회모드)·이미지 팝업이 노출됨 | 통과 |

## 확인 필요

| 항목 | 내용 |
|------|------|
| 삭제 확인 처리 | 삭제 시 확인 다이얼로그(확인/취소)가 필요한지 |
| 썸네일 생성 방식 | 업로드 시 서버에서 썸네일을 자동 생성하는지, 원본을 축소하여 표시하는지 |
| 업로드 파일 제약 | 허용 이미지 형식(jpg, png 등), 최대 용량 제한이 있는지 |
| 권한 | 모든 사용자에게 등록·수정·삭제가 허용되는지, 권한 구분이 있는지 |
| 삭제 권한 | 등록자만 삭제 가능한지, 모든 사용자가 삭제 가능한지 |
| 페이징 단위 | 페이지당 표시 건수(10건, 20건 등) |
