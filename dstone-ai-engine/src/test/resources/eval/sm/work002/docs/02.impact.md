## 결정 필요 사항

1. 메뉴 URL: 실제 DB tbsy_resource의 TS_300 '이미지게시판'이 resource_url='/sample/board/sampleBoard.go'로 샘플게시판을 가리키고 있음. 이미지게시판 전용 URL(예: /sample/board/imageBoard.go)로 바꿀지, 기존 행을 그대로 쓸지 결정 필요. seed.sql에는 TS_300 INSERT가 없어 스크립트와 실DB가 어긋남 - seed.sql에 반영할지도 결정 필요.
2. 이미지게시판 테이블: 신규 테이블(예: tbts_image_board)을 만들지, 기존 tbts_sample_board를 재사용할지 결정 필요(현행에는 이미지게시판용 테이블이 없음).
3. 파일 저장: 기존 tbsy_file_info + FileService#imageSave를 재사용할지, 게시판 전용 저장 방식을 둘지 결정 필요.
4. 요구사항 문서의 '확인 필요' 항목(삭제 확인 다이얼로그, 썸네일 생성 방식, 업로드 파일 제약, 권한, 삭제 권한, 페이징 단위)은 설계 단계에서 확정 필요.
5. FAQ: 실DB에 tbts_faq와 메뉴만 있고 소스가 없음 - 본 요청과 무관하므로 손대지 않음(확인 필요).
