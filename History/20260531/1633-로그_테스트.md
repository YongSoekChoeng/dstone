## 답변

로그 설정을 확인했습니다. 어떤 테스트를 원하시나요?

현재 설정 요약:

| 항목 | 내용 |
|---|---|
| 프레임워크 | Log4j2 |
| 콘솔 패턴 | `%d{yyyy-MM-dd hh:mm:ss} %5p [%c] %m%n` |
| 파일 경로 | `${APP_HOME}/LOGS/${APP_NAME}/execution/execution.log` |
| 롤오버 | 일별, 백업 3일 보관 |
| 기본 레벨 | INFO |
| SQL 로그 | `jdbc.sqltiming`, `jdbc.resultsettable` → INFO, 나머지 OFF |
| dstone 앱 로그 | INFO |

테스트 방향을 알려주시면 도와드리겠습니다:
1. **특정 클래스에서 로그 출력 확인** — 로그 코드가 있는 파일 확인
2. **SQL 로그 활성화** — `jdbc.sqlonly` 레벨 변경
3. **DEBUG 레벨로 전환** — 상세 로그 확인
4. **콘솔 패턴 수정** — 시간 포맷 등 (`hh`가 12시간제인데 `HH` 24시간제로 수정 필요할 수 있음)
