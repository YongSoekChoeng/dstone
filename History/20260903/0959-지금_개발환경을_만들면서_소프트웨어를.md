**조사 방식**: 요청하신 목록(jdk, mysql, rabbitmq, redis, kafka, maven, docker, jenkins) 외에도 실제 시스템(`dpkg`, `systemctl`, `/opt`, `/usr/local/bin`, `~/.bash_history`)을 조사해서 PostgreSQL, Node.js, kubectl/kind, Kafbat UI(Kafka 관리 콘솔)도 함께 찾아 포함시켰어. `~/.bash_history`에 남아있던 실제 설치 명령(Kafka tar.gz 설치, Docker 공식 저장소 등록, kubectl/kind 바이너리 다운로드)을 그대로 재현 가능한 형태로 각 문서에 기록했어.

**참고할 점**
- MySQL/PostgreSQL/Redis/RabbitMQ/Maven/JDK/Git은 모두 Ubuntu 26.04 공식 저장소 apt 설치, Docker/Jenkins/Node.js는 각 벤더의 서드파티 apt 저장소, Kafka/Kafbat UI/kubectl/kind는 수동 바이너리 설치임을 확인했어.
- WSL 특성상 대부분 서비스가 부팅 시 자동시작되지 않고 `/usr/local/bin/start-*.sh`/`stop-*.sh` 스크립트로 수동 기동하는 구조라, `environment.md` 상단에 이 운영 원칙을 별도로 적어뒀어.
- Kafbat UI의 정확한 최초 다운로드 URL은 히스토리에 남아있지 않아 GitHub 릴리즈 페이지 참조로 대체 기록했어. 정확한 URL을 알려주면 문서에 반영할게.

이후 소프트웨어가 추가되거나 설정이 바뀌면 같은 구조(`environment.md` 표 + `docs/software/{이름}.md`)로 갱신해달라고 요청하면 돼.
