## 답변

Agent 디자이너 양식에서 모델 섹션을 왼쪽 열의 기본 아래로 옮겼습니다. 이제 왼쪽은 위에서부터 기본, 모델이고, 오른쪽은 실행입니다. 화면을 띄워 확인하지는 않았고, JS 문법 검사만 통과했습니다.

- **`workflow-designer.js`:** 양식 HTML을 왼쪽 열(기본·모델)과 오른쪽 열(실행)로 나눴습니다. 전에는 실행이 모델 섹션 안의 소제목이어서, 실행을 별도 섹션으로 뺐습니다.
- **`main.css`:** 새 열에서 첫 섹션의 윗줄과 여백이 없어지도록 선택자를 하나 추가했습니다. 좁은 화면에서 한 열로 접히는 기존 규칙은 그대로입니다.

열 높이는 왼쪽이 기본(5행)과 모델(4행), 오른쪽이 실행(6행)이라 서로 비슷합니다. 서버를 재기동하거나 새로 빌드할 필요는 없습니다. 브라우저에서 새로고침하면 됩니다. 커밋은 하지 않았습니다.
