## 끝난 것 (M5 구현·검증)

- **끊겼던 `anybiz_prd` 재분석**: 오류 0으로 끝났습니다 (SQL 연결 1,967건, 여는 화면 463, 요청 주소 1,677).

- **Struts 플러그인**: Struts 1·2 설정 파일에서 진입점, 계층, 끝나고 가는 화면을 만듭니다.
- **`struts-app` 표본**: Struts 1 + iBATIS + JSP로 화면 → 액션 → DAO → SQL → 테이블이 이어지는 것을 확인했습니다. 검색도 SQL·화면 문서까지 됩니다.
